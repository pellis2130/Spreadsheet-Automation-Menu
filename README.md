# Spreadsheet Automation Menu

## Project Overview

This Python project is a Spreadsheet Automation Menu that demonstrates the use of data structures, loops, decision structures, user input validation, and date and time functionality.

The program displays three spreadsheet automation options and allows the user to select an option. It then determines whether the user's selection is valid or invalid.

## Menu Options

The application provides the following options:

1. Input Data
2. View Current Data
3. Generate Report

## Features

- Displays the Student ID in the application title
- Stores menu options in a Python tuple
- Uses a `for` loop to display the menu options
- Accepts user input
- Uses `if-else` statements to validate the user's selection
- Displays an error message when an invalid option is selected
- Displays the selected option when the input is valid
- Displays the current date and time for valid selections
